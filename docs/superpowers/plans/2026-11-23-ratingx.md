# RatingX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans

**Goal:** Full Electron + React desktop app for searching, organizing, and rating films/series/anime with public profile export and auto-updater.

**Architecture:** Electron main process owns SQLite DB and IPC handlers; React renderer owns all UI via React Router + Zustand; TMDB API called from main process.

**Tech Stack:** Electron 32, React 18, TypeScript, Vite 5, Tailwind CSS 3, Framer Motion 11, Zustand 4, React Router 6, better-sqlite3, Lucide React, electron-builder

**Spec:** `docs/superpowers/specs/2026-11-23-ratingx-design.md`

## Global Constraints

- Node 24, npm 11
- Electron 32 (not 33+)
- React 18 (not 19)
- Tailwind 3 (not 4)
- All DB calls in main process only
- TMDB key stored via `safeStorage`
- SQLite WAL mode
- No external auth

**Interfaces produced:**
- `db` singleton: `better-sqlite3` Database instance with WAL mode
- Tables: `sections`, `library_items`, `profile` (see schema below)
- `ipcMain.handle(channel, handler)` for all 15 channels in spec

Schema:
```sql
CREATE TABLE IF NOT EXISTS sections (
  id TEXT PRIMARY KEY, name TEXT NOT NULL, icon TEXT DEFAULT '📁',
  display_order INTEGER DEFAULT 0, created_at INTEGER NOT NULL
);
CREATE TABLE IF NOT EXISTS library_items (
  id TEXT PRIMARY KEY, tmdb_id INTEGER NOT NULL, media_type TEXT NOT NULL,
  title TEXT NOT NULL, poster_path TEXT, year TEXT, overview TEXT,
  section_id TEXT NOT NULL, rating REAL, note TEXT DEFAULT '',
  added_at INTEGER NOT NULL, rated_at INTEGER,
  FOREIGN KEY(section_id) REFERENCES sections(id)
);
CREATE TABLE IF NOT EXISTS profile (
  id INTEGER PRIMARY KEY CHECK(id=1),
  username TEXT DEFAULT 'User', bio TEXT DEFAULT '', avatar_path TEXT DEFAULT '',
  created_at INTEGER NOT NULL
);
```

- [ ] Write `src/main/db.ts`: open SQLite at `app.getPath('userData')/ratingx.db`, run WAL pragma, run CREATE TABLE IF NOT EXISTS for all 3 tables, export `db` singleton
- [ ] Write `src/main/preload.ts`: use `contextBridge.exposeInMainWorld('api', {...})` exposing `invoke(channel, ...args)` wrapper around `ipcRenderer.invoke`
- [ ] Write `src/main/ipc/sections.ts`: handle `sections:getAll`, `sections:create`, `sections:update`, `sections:delete`
- [ ] Write `src/main/ipc/library.ts`: handle `library:add`, `library:update`, `library:remove`, `library:getAll`, `library:getSection`, `library:export`, `library:import`
- [ ] Write `src/main/ipc/search.ts`: handle `search:query` → fetch `https://api.themoviedb.org/3/search/multi` with key from `safeStorage`; cache last 20 queries in memory Map
- [ ] Write `src/main/ipc/profile.ts`: handle `profile:get`, `profile:update`, `profile:exportHtml`
- [ ] Write `src/main/ipc/updater.ts`: handle `app:checkUpdates` → fetch `https://api.github.com/repos/davCreate/RatingX/releases/latest`, compare with `app.getVersion()`
- [ ] Write `src/main/index.ts`: create BrowserWindow (1200×800, min 900×600, `webPreferences: { preload, contextIsolation: true, nodeIntegration: false }`), register all IPC handlers, load vite dev URL in dev or `dist/renderer/index.html` in prod

## Review Focus

1. **Empty TMDB key** — search page must show "Set your TMDB API key in Settings" state, not crash
2. **Section deletion with items** — must cascade-delete library items or offer to move them
3. **Import JSON with unknown sectionIds** — create a default "Imported" section and remap
4. **Rating of 0** — must be stored and displayed as `0/10`, not treated as null/falsy
5. **Offline** — if TMDB fetch fails, show cached results or "No internet connection" error, never crash
